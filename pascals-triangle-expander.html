Pascal's Triangle Expander

Multiplying out (x + y)⁵ by hand takes a long time. First, look for a pattern in some smaller powers. Then use that pattern to expand any binomial quickly.

Part 1 · Discover the pattern

A. Collect the numbers

These are already multiplied out for you. Type the coefficient (the number in front) of every term into the boxes on the right, one row for each power.

If no number is written in front of a term, its coefficient is 1. So x2 means 1x2. The row for (x + y)0 = 1 has just one number: 1.

  7. Look at the 2 in row 2. Which two numbers sit right above it in row 1? + = 2

Write the triangle with each row centered under the one above it. Every number sits between two numbers in the row above. Questions 6 and 7 ask you to add those two numbers.

C. Predict the next rows

Use your patterns to predict the coefficients of (x + y)4 and (x + y)5 without multiplying.

Start and end each new row with 1. For each number in between, add the two numbers right above it. Row 4 begins 1, 1 + 3, …

Why does adding work?

Here is (x + y)4 = (x + y)(x + y)3 multiplied out. Multiply every term of row 3 by x, then by y. Like terms line up in the same column.

Every column gets one term from the × x row and one from the × y row. Those are the two numbers above it in the triangle, which is why we add them.

The expander unlocks once you finish part C.

You found Pascal's triangle

The triangle of numbers you built is called Pascal's triangle. Row n gives the coefficients of (x + y)n. Next, you'll use it on harder binomials like (2x − 3)4.

2. Pascal's triangle

Click any number to use that row. Hover or tap a number to see where it comes from.

  • Each row starts and ends with 1.
  • Every other number is the sum of the two numbers above it.
  • For a power of n, use the row that starts 1, n, … (row n). It has n + 1 numbers, so the answer has n + 1 terms.

3. Expand it step by step

  1. Write down row n of Pascal's triangle. These are the coefficients.
  2. Write the first term with powers going down from n to 0.
  3. Write the second term with powers going up from 0 to n.
  4. Simplify each power.
  5. Multiply down each column to get one term.
  6. Add the terms together.

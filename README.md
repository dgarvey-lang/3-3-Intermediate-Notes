# 3.3 Solving Systems of Equations by Elimination

Interactive student fill-in notes for **Lesson 3: Solving Systems of Equations by Elimination**.

- `lesson3-student-notes.html` – student page with answer boxes, a **Check my work** button and an **I need help** button (step-by-step hints) for every section.
- `index.html` – opens the student page (handy for GitHub Pages).

Sections: elimination steps, choosing to add / subtract / multiply first, four examples (add, subtract, multiply one equation, multiply both), special cases (no solution and infinite solutions), and a school-play ticket word problem.
**Split screen:** questions scroll on the left; a **scratch whiteboard** stays on the right and switches to whichever problem is on screen (it shows that problem at the top). Draw with a finger, stylus, or mouse — pen colors, eraser, undo, clear. On phones, a "✏️ Scratch board" button opens it full screen.
Answers and drawings are saved in the student's browser so a refresh doesn't erase their work.

## Pascal's Triangle Expander

`pascals-triangle-expander.html` – a manipulative for expanding binomials with Pascal's triangle.

- **Part 1 · Discover the pattern** – students read the coefficients off (x + y)⁰ … (x + y)³, answer pattern questions (exponents go down/up, exponents add to n, n + 1 terms, each number is the sum of the two above), then predict rows 4 and 5. A "Why does adding work?" table multiplies (x + y)(x + y)³ so like terms line up. The rest of the page unlocks when they finish (a "Skip ahead" link is there for review days).
- **Part 2 · Use the triangle** – build any (ax ± b)ⁿ or (ax ± by)ⁿ up to n = 10, click a row of the triangle, and step through the expansion: coefficients → first-term powers down → second-term powers up → simplify → multiply → add. Hover a column to see its triangle number.
- **Your turn** – random practice problems with Check my work and a Walk me through it button.

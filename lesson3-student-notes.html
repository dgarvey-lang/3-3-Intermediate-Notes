Notes: Solving a System by Elimination

Read these steps. You'll use them for every example below.

  1. Line up both equations so the x's, y's, equal signs, and numbers are in columns (Ax + By = C).
  2. Make opposites: look for a variable whose coefficients are opposites (like 3y and −3y). If there isn't one, multiply one or both equations so there is.
  3. Add the equations together. One variable is eliminated (it cancels out).
  4. Solve for the variable that is left.
  5. Substitute that value into either original equation to find the other variable.
  6. Check the point in both original equations.

Tip: if the coefficients are the same (like 2x and 2x), you can subtract the equations instead of adding. Remember to subtract every term!
